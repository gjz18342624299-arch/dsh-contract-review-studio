# 首次使用演示项目

空白工作台首次打开时自动创建一个「演示项目 · 从风险到修改」，内含一份虚构的网站设计服务合同和六条预设风险：全额预付、验收期限、成果归属、赔偿范围、提前解除结算及争议解决。

点「打开演示项目」进入后，可以查看风险原因和建议，定位原文，采纳建议查看正文增删，保留原文或撤回处理，保存演示版本并下载演示 Word。演示使用本地正文预览，不要求先配置 ONLYOFFICE 或模型；不会把预设风险冒充已运行的模型结果，也不把演示处理记录冒充远程 Word 保存结果。

已有项目或合同的工作台不自动添加、不重置、不替换任何材料，项目页提供「添加演示项目」入口。重复打开不会复制或重置演示修改；演示移除后不会在下一次启动自动重建，可以通过入口显式添加。演示内容和处理状态仅保存在当前工作台存储中。

真实合同继续使用现有模型和在线 Word 流程。演示内使用的企业名称和合同均标明虚构，建议仅用于教学，不作为法律结论或实际签约文本。公共包不附带作者的真实合同、企业模板或服务凭据。

验证覆盖首次空数据、已有数据保护、重复初始化、移除后不自动恢复、手动添加与 ID 冲突保护、修改撤回、无需编辑器的演示操作和真实合同委托。完整原生 Desktop 视觉和操作验收需在安装后确认，自动化检查不替代该结果。
