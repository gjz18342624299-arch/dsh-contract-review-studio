# 首次使用演示项目

安装后首次打开时，项目列表会自带一个普通的「演示项目 · 从风险到修改」，内含一份虚构的网站设计服务合同和六条预设风险：全额预付、验收期限、成果归属、赔偿范围、提前解除结算及争议解决。它和其他项目使用相同的列表与打开方式，首页不保留专门的演示入口。

从项目卡片点「打开项目」，再打开其中的演示合同，即可编辑自带的真实 DOCX。可在 ONLYOFFICE 中编辑正文，定位原文、应用建议、保存版本和导出 Word，使用与普通合同相同的编辑与保存流程。Word 编辑需要可用的 ONLYOFFICE 服务；六条预设风险可直接查看，无需先配置模型。预设风险标明为演示关注点，不代表已运行模型或已核验法律结论。主动发起 AI 审查或问答时，按普通合同流程使用所选模型。

已有材料但从未添加过演示的工作台会补充这一个项目，保持原有项目顺序、当前合同和编辑内容。重复打开不会复制或重置演示。发现同名项目或固定 ID 被其他资料占用时不覆盖、不添加。演示原件及工作台处理记录保存在当前工作台中，打开在线 Word 时该虚构合同会发送至已配置的文档服务。

不需要演示时，可在卡片或项目材料页点「删除项目」，确认后从列表移除。项目、合同、审查记录和版本保留在本地回收记录中，原始文件仍保留；不会删除其他项目或仍被其他项目引用的合同。删除标记随空列表一起保存，因此删除唯一演示项目后刷新也不会自动恢复。

旧版纯前端演示首次打开时自动准备可编辑 Word。此前采纳或手动编辑的内容会保留为 Word 正文，并新增「升级 Word 前的演示记录」用于比较；旧版本记录和处理状态不会清空。升级前的修改已构成 Word 基线，不冒充可在编辑器中撤销的本次修订。已有真实 Word 会话的演示直接复用，出现来源或工作稿标识冲突时会停止准备并明确报错，不用自带材料覆盖旧稿。

真实合同继续使用现有模型和在线 Word 流程。演示内使用的企业名称和合同均标明虚构，建议仅用于教学，不作为法律结论或实际签约文本。公共包不附带作者的真实合同、企业模板或服务凭据。

自动化验证覆盖自带 DOCX 与风险逐字引用一致、一次性添加及既有材料保护、同名和 ID 冲突保护、删除归档、移除后不自动恢复、共享资料保护、原件准备去重、旧演示修改迁移、迁移失败后的记录保护、保存失败重试、删除与准备并发保护、已有 Word 会话保护，以及普通 Word 操作委托。另以独立 Chromium 访问已配置的 Desktop 后台，实际通过 Word 打开、原文定位、采纳修改、保存版本及下载文件核对；这项证据不冒充原生 Desktop 窗口实测。
